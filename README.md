# Emmanuel Ekwere Willie — CV Portfolio Website

A responsive, static personal portfolio website with a dark technology-inspired design, subtle animations, experience timeline, projects, skills, education, certifications, contact links and downloadable CV.

## Preview locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Keep the `assets` folder in the same directory so the CV download works.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a new **public** repository, for example `emmanuel-willie-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, the `assets` folder, and this README to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published URL in the Pages section once deployment finishes.

Alternative: Netlify can host the extracted folder using its manual deploy/drag-and-drop workflow. Follow the current instructions in Netlify's dashboard.

## Before publishing
- Confirm that you want your phone number and email address publicly visible.
- Check dates, role titles and the project status labels for accuracy.
- The Felton database, cybersecurity review and lead-generation workstreams are described as initiatives/assessment/in-development, not as completed production deployments.
- The download included is the updated Word CV.
- Add your LinkedIn profile URL if you want a direct LinkedIn link; one was not included here because a verified URL was not available in the source CV.
- Google Fonts requires internet access; the page otherwise uses local HTML, CSS and JavaScript.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — responsive styling and visual effects
- `script.js` — navigation, scroll progress and reveal animations
- `assets/Emmanuel_Ekwere_Willie_CV.docx` — downloadable CV
